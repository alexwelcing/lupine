## Revenue Stream 1: Software License + Consulting (~400 words)
- **Product:** atlas-distill — Rust engine for error-geometry analysis in molecular dynamics
- **Model:** Yearly SaaS license ($50K–$250K/yr, tiered by compute volume) + implementation consulting ($500–$1,500/hr)
- **Target customers:** National labs (NIST, ANL, ORNL), semiconductor companies (Intel, TSMC, Samsung), defense contractors (Boeing, Lockheed), materials startups
- **Value prop:** Turn months of benchmarking into hours; catch model failures before they ship; standardized compliance reporting
- **Differentiator:** Only tool that detects Simpson's paradox in multi-potential benchmarks; only tool with formal causal-fallacy guardrails
- **Traction:** Open-source MIT license on GitHub (1 star → enterprise leads); inbound from OpenKIM community

## Revenue Stream 2: IP Licensing for Discovered Materials (~400 words)
- **Product:** Computational materials discovery pipeline using hyper-ribbon geometry to guide screening
- **Model:** Patent filing → exclusive/non-exclusive licensing to materials manufacturers; milestone payments + royalties (3–7% net sales)
- **Process:** Hyper-ribbon analysis identifies "stiff directions" in error space → predicts which element-property combinations are ripe for new potential development → automated screening of candidate structures
- **Target categories:** Battery electrolytes (solid-state Li conductors), high-temperature alloys (aerospace), catalytic surfaces (hydrogen economy)
- **Example pipeline:** Identify elements with PR > 1.5 (underparameterized in literature) → run MACE/CHGNet → validate with DFT → file composition patents
- **Competitive moat:** No other platform combines sloppy-model geometry with active discovery; error-manifold structure is proprietary signal

## Revenue Stream 3: Investment Trading Strategy (~400 words)
- **Product:** Quantitative materials-research trading signals derived from atomic simulation open data
- **Model:** Family office / institutional LP investment ($5M–$50M AUM per vehicle); 2/20 fee structure; quarterly redemption
- **Signal generation:**
  1. Mine OpenKIM, Materials Project, AFLOW for publication-rate anomalies (sudden surge in DFT calculations for a given element → suggests academic/industrial interest)
  2. Hyper-ribbon analysis reveals which elements are "hot" (many new potentials being fitted) vs "cold" (neglected but physically important)
  3. Cross-reference with patent filings, supply chain data, government funding announcements
  4. Generate long/short signals on: mining equities (Li, Co, Ni, REE), chemical companies (BASF, DuPont), battery manufacturers (CATL, BYD, Tesla)
- **Edge:** First mover in applying atomic-simulation metadata to capital markets; uncorrelated to traditional commodity signals
- **Risk management:** Max 15% single-position; volatility targeting; monthly rebalancing
- **Team:** Quantitative researcher (Alex Welcing) + capital markets advisor [to be hired]
