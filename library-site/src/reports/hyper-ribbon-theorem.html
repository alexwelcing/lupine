Theorem shape

The page proves less, and therefore says more clearly what matters.

The formal layer is a gate over a scalar certificate. It does not claim that every low-dimensional error cloud is a full hyper-ribbon. It says that when a runtime packet supplies the right bounds, an accepted projected correction remains inside the projection tube, keeps stiff-axis drift bounded, clears support obligations, and inherits the existing accuracy commitment when the measured error improves.

\operatorname{acceptsProjectedRibbon}(c) \Rightarrow d_{\mathrm{proj}}(c)\le d_{\max}(c)\;\land\; s_{\mathrm{drift}}(c)\le s_{\max}(c)

Claim ladder

Compression

Projected gate

The scalar certificate checks complement dominance, projection distance, stiff drift, support lift, and support floor before a projected correction can be accepted.

Scientific win

The theorem remains conditional on measured improvement. The site should report wins only when the benchmark packet beats its baseline.
