# Documentary-source publication representation

The original README and MIT license bytes are retained in adjacent `.bytes.json`
wrappers under `sources/`. Encode each wrapper's `text` as UTF-8 to reconstruct
its exact original bytes, Git blob and receipt hash. Both source audit and
independent review refer to those originals. The original cache files remain
unchanged.

The ordinary README and MIT text files are readable copies with line-end
whitespace removed and LF line endings. All words, the complete copyright and
permission notice, and citation text are unchanged. These readable copies do
not claim the original Git blob hashes. The exact mapping and first whitespace
check failure are retained in
`../phase2-finite-compatible-verification-v1/publication-checks/`.
