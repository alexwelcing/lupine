JavaScript errors; all 311 runtime files in the root’s v2 overlay remained
unchanged. The normal run is under `first/`. Its exact source maps and reviewer

benchmark and selection helpers. It verifies an independently enumerable pair

JSON export, the empty cap and hypothetical census, per-form state and real HTTP

the newest result. The invocation exited 1 at that exact assertion in 6.537
seconds. This expected negative result is retained, not a product failure or a
passing production test. The product source files were never mutated.
