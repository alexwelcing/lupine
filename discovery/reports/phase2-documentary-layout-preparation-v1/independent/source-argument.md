The source bindings and final verdict are recorded separately; this argument is not an execution receipt.

The new worksheet target uses a bounded stack of allowed parent-child frames. A start event checks supported expanded names, attributes, ancestry and resource counters before retaining its frame. Root children are unique and exactly one sheetData is required. A row stores only its explicit canonical row index; a cell requires its own canonical reference, agrees with its parent row, has a distinct position and one of the closed declared storage forms. End events enforce the cell-content conflicts before publishing a cell record into the private accumulator. Opaque text is not retained by the target. Non-whitespace data outside the explicit opaque leaves, including inter-element tails after a leaf ends, is rejected.

Canonical coordinates admit only uppercase columns A through XFD and positive rows through 1048576, without inferred positions. Unique sparse cells are sorted numerically; absent cells are never created. Merge declarations require increasing, nondegenerate canonical rectangles. Pairwise closed-rectangle intersection checks reject both duplicates and overlaps; declared merge count must agree with the represented list. These are structural declarations, not judgments about cell semantics or a record denominator.
