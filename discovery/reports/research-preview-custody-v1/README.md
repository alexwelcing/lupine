backup, restored-environment study or complete public reconstruction has been
demonstrated. The release wheel/source archives intentionally exclude ignored
scientific custody. Those software artifacts do not back up the experiment.

still requires the exact registered source and original allocation/custody.

This review inspected source and documentation only. It opened no private
scientific files or registry, created no bundle and transferred no data. A
concrete private copy-plan remains in the ignored handoff area with unresolved
parent-supplied slots; it is not an executed backup manifest. Local reversible
implementation remains within the standing project authorization. A private
external transfer requires an identified authorized destination; none was chosen
or attempted. No new user approval is requested by this report.

These limits remain explicit in the research-preview scope. Scientific
reproduction already executed is preserved as evidence; a claim of protection
against workspace loss or portable restored execution is not made.
