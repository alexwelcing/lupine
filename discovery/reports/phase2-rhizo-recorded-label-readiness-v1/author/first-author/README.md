# Stored Rhizo label readiness — generated-data candidate

This small standalone candidate inspects the four archived prediction/reference
positions for each of 36 fixed IDs. It makes no reference choice, invokes no
binder, reads no reference container and computes no residual, rank, fit, split,
census performance or new allocation. Every result remains `NOT_ADMITTED` with
actual reference choice `UNKNOWN`. **No actual retained-object invocation has
occurred.** The [contract](contract.json) was frozen before implementation.

The exact public object manifest fixes 36 bound evidence objects, 126,885 bytes;
its optional two-reference extension is not opened by this candidate. The
original 36-ID / 43-location / 172-edge frame is preserved as context. Its edges
are never promoted to selected reference identities. A non-null archived
reference annotation may predate binding; it does not prove selection by the
archived binder or physical accuracy.

`inspect_synthetic(payloads, frame_raw, inputs_raw)` accepts generated byte
buffers under the 36 exact repository path keys and exact pinned public frame
and object-manifest bytes. It returns `(public_report, private_projection_or_null)`.
All frame/input pins and buffer keys/types/lengths are checked before any buffer
content is hashed. Each fixture identity is computed at its recorded exposure
stage; known actual identities are rejected before JSON parsing. This fixture
identity calculation is not independent verification of an actual source.

`run_synthetic_files(paths, payload_specs, frame_raw, inputs_raw, output_slot)`
exercises file behavior with generated temporary files. Each ordered spec has
exactly `path`, `bytes`, `sha256`, `git_blob_sha1`; fixed paths remain in original
order and generated lengths may not exceed the corresponding original cap.
Actual identities and custody paths are refused. Tests may challenge shared
`_run_files` using fixture guards, but must not call the actual `run_retained`
entry point. Root owns any later fixed manifest and actual invocation.

The parser performs one strict JSON grammar pass per immutable buffer. Root
depth is one and depth is at most 32; the 20,000-node bound counts values and
object keys. Decoded strings, including keys, are at most 16,384 characters.
String allocation occurs within the whole-file byte cap before its tighter
decoded-length check. UTF-8, duplicate decoded keys, standard JSON grammar and
paired Unicode surrogates are checked. The property-list limit is **512 records
in `properties`**, not 512 keys in every JSON object; other structure remains
bounded by source bytes, depth and node count.

The schema marker, literal material/model ID and declared 64-character lowercase
hex input-hash format must match their contract. Input-hash format is not a
comparison with an unopened companion. Property rows must be objects with string
names. Schema/context/container failures stop at the first closed category;
no source is retried or substituted. Unselected properties and fields are fully
parsed but are not intentionally projected.

`ExactJSONNumber` retains the original JSON token. A token denotes exactly its
signed integer mantissa times ten to its explicit exponent minus fractional
digit count; no float, numerical string or boolean is coerced into a label.
Selected numbers allow at most 128 mantissa digits (including zeros), absolute
explicit exponent at most 1024 and absolute decimal scale at most 1024. Valid
JSON decimal tokens denote finite rationals; these additional limits are
engineering limits, not physical plausibility ranges. Out-of-limit tokens stay
exact privately with a categorical failure state. Unselected number tokens
receive syntax checking only. There is no numeric computation comparing labels.

Each fixed position is `ABSENT`, `SINGLE` or `AMBIGUOUS`. Duplicate matching rows
are all retained privately; none is selected. Public field states on absent or
ambiguous positions remain `NOT_CHECKED`, with record state making the dependency
explicit. A single row is a complete pair only with literal expected unit and
two valid exact number tokens. Units are `eV` for vacancy and `J/m^2` for each
gamma property. Citation presence/type/empty/whitespace/nonempty states are
separate from numeric-pair completeness and do not establish citation adequacy.
Tolerance is separate and optional: missing/null are permitted; a valid negative
nonzero tolerance is flagged, while exact signed zero is nonnegative. Tolerance
is never substituted for a reference, used for matching or called uncertainty.

The private output contains the scoped exact number tokens and citation/unit
strings, declared input hash and each matching record's original property-array
ordinal. Invalid nonnumeric values are represented only by categorical type;
arbitrary objects/arrays/strings in a numeric field are not recursively copied.
Missing, invalid and ambiguous states survive a completed inspection. A global
source/parser/context failure returns no partial private projection, but does
not erase prior materialization or exposure.

Public output contains only the fixed graph/identities, closed states and
progress. `positions_inspected` and per-object `positions_materialized` count
fully returned position projections, including absent positions. Global
`selected_historical_labels_materialization_started` is set before inspecting
a nonempty selected record set. `selected_historical_labels_materialized` means
at least one such whole position projection completed; its false value does not
deny partial work when the started flag is true. Global JSON completion becomes
true immediately after all 36 parsers complete, independently of later context
or projection failures. Historical labels/citations and the whole mixed JSON
are exposed to the machine; this is not a fresh holdout.

The future actual wrapper binds its own source, contract, frame, manifest and
documentary source pins before access and before each source read/output. It
exclusively reserves its fixed output directory before opening a target object.
Each fixed source is opened once with no-follow and regular-file checks, read
once at exact size plus one byte, and verified by size/SHA256/Git blob identity
before parsing the same buffer. Files and slots are never overwritten or retried.
These guarantees assume the controlled runtime and ordinary directory ownership,
not an arbitrary hostile process. No network or upstream code is invoked.

Private output is written only after complete scoped inspection. A later public
write failure preserves any successful or possible partial private write in a
closed failure receipt. A processing error remains the first reason if output
also fails. Actual researcher inspection is not observable by this program;
returning/writing historical labels and potentially outcome-bearing citations
makes them available and cannot certify non-exposure.

An inspection can finish while retaining invalid/incomplete labels. The
`all_144_pairs_complete` field concerns only this recorded-label definition.
It is null after global failure and is never a physical or benchmarking pass.
Citation and optional tolerance booleans are separate. The historical figure
map remains distinct from the re-relaxed calculator, and every original
scientific gate remains unresolved by generated tests.
