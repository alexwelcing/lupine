## Independent physical and semantic fixture

`generated_package.py` packs local headers, central directory and EOCD directly with stdlib struct/zlib. Its invented baseline has 15 local headers, five independent A220 areas, and three completed areas before the old first unfamiliar-kind rejection. An opaque binary part and its generic relationship name are deliberately outside the old finite member-kind table. Every other physical predicate is ordinary, with matching local/central declarations. Documentary role order, sheet IDs, relationship IDs and targets deliberately differ.

The fixture includes two complete documentary worksheets, one record worksheet with explicit header/data/blank/note/aggregate rows, duplicate asserted specimen IDs, missing metadata and endpoint cells, and distinctive invented numerical canaries. Invalid XML canaries occur only in opaque payloads. The baseline is a generated engineering object, not a model of actual member names or meanings.

## Package and relationship challenges

- Safe unfamiliar ordinary names are accepted by the new restricted grammar without names/payloads appearing in public output. Case collisions, case-insensitive prefix collisions, trailing-dot segments, percent/query/fragment/space/brackets, traversal and canonical-path violations block. Keep the exact Media Types item special.
- Reserved relationship spellings are classified case-insensitively and invert to one existing source part. Dangling, empty-leaf, relationships-to/from-relationships, Media Types source/target, and a normal name falsely declared as Relationships type block. Relationship identity and resolved media type agree in both directions.
- Content types cover Default and Override, ASCII-case-insensitive duplicate keys, Override precedence, unused valid Defaults, missing coverage, dangling/Media Types Overrides, malformed token/token types and wrong known-role type. No semantic role is inferred from an unfamiliar extension or declared type.
- Internal targets resolve relative to the source part, not package/workbook by convenience. Literal dot segments within bounds and package-absolute paths work; above-root escape, empty segment, scheme/authority/percent/query/fragment/backslash/external target block. Keep exact URI Type spelling; malformed percent, authority/userinfo/port, whitespace and unsupported schemes block. Duplicate IDs/targets block.
- Root/workbook validators remain strict despite more general graph syntax. Unknown root/workbook relationship types, unbound sheets, wrong worksheet target pattern, missing documentary role, case-near role names and wrong namespace-qualified r:id block. Exact role names resolve through r:id, never ordinal or sheetId.
- Spy on every ZipFile member opener. Layout opens each metadata member once plus precisely the two documentary sheets, never shared strings, styles, record worksheet or opaque payloads. Unknown opaque CRC/body content is not verified or declared harmless. Malformed/changed G34 replay expectations stop before the first XML/member open.

## Layout, documentary and frame phases

- Complete sparse cell/type/formula/merge inventories are atomic across both roles. Partial second-role failure clears both outputs and preserves all machine exposure. Reject XML grammar, namespaces/namespace declarations, duplicate coordinates, overlap, malformed bounds, DTD/entity/PI and resource-cap violations.
- Documentary text is inaccessible without the complete frozen manifest and qualified exact prior receipts. Manifest source/producer/receipt/coordinate/type/merge/semantic-field drift blocks. Plain inline/shared strings work only as declared; wrong/missing relationship, malformed shared index, rich text, formula/cache-derived text, mixed definition/numerical examples and unsupported dependencies retain a blocked/unknown mapping rather than guessing.
- Frame requires one complete bound record sheet/row/metadata/join specification and documentary receipt; metadata meaning cannot be inferred from layout or values. Retain every original explicit header/data/blank/note/summary row and ambiguity, including duplicate asserted IDs. Archive-row identity remains separate from asserted physical-test identity. No trimming, deduplication, source choice, eligibility or numerical endpoint conversion.
- Preserve reference tokens and source conflicts; DOI coincidence alone never unions sources. Distinguish supported/unresolved joins, missing/present metadata from numerical validity, and archive count claims from physical-unit counts. Overlap remains unknown without an authenticated target-redacted exposure manifest.
- Change endpoint/cached/opaque canaries while preserving allowed lexical metadata: no endpoint values, hashes, ranges, lengths, scores or performance may escape. Allowed scientific citations appear only through manifest-declared provenance fields. Every traversal can privately expose unselected character data; flags must disclose that exposure rather than asserting target-free processing.

## Execution and scope

Generate fixtures independently. Freeze source and expected API/binding/replay semantics before first candidate invocation. Preserve first failures and distinguish fixture/harness repairs from implementation defects. No actual/private data, production guard, upstream reader invocation or network. Root owns actual phase admission; this suite cannot authorize it or establish physical truth.
