# Fixed-archive claim boundary

[The source-bound clarification](README.md) and [independent final review](review-final.json)
distinguish randomized inference about a fixed recorded frame from inference
about new physical units. The hypergeometric argument is written counting;
no new experiment, runtime feature or test execution is claimed. The original
reviewed text and two precision additions remain preserved.

This is a design boundary, not a new study registration or an exception to
G20/G21. Source semantics, pairing, frame, exposure, provenance and cost still
need justification before a proposal. Duplicate records, unknown lineage and
measurement uncertainty cannot be promoted into independent physical evidence.
No existing acceptance criterion or scientific NO-GO result is changed.
