# Primary GitHub source lead: tmQM

**tmQM is a defensible next source-readiness lead, with admission still unestablished.** Its curator repository directly supplies versioned documentation and an MIT license, plus a common property-file description and structural identity roles. This survey acquired no numerical dataset file, model result, figure or full paper. It selected no target pair, feature set, threshold, model, allocation or benchmark.

The source is [uiocompcat/tmQM](https://github.com/uiocompcat/tmQM), pinned to commit `ece824419c9006fe66436daf233822b75533b82f`. That is a server-declared file identity, not a verified download; its contents remain unopened.

The README identifies the UiO Computational Catalysis Group and cites the original paper by **David Balcells and Bastian Bjerkem Skjelstad**, *tmQM Dataset—Quantum Geometries and Properties of 86k Transition Metal Complexes*, [DOI10.1021/acs.jcim.0c01041](https://doi.org/10.1021/acs.jcim.0c01041). [Crossref metadata](paper_metadata/projection.json) independently matches that title and author pair. The repository's MIT copyright notice names Skjelstad. These facts support the curator provenance; a GitHub `fork:false` flag alone would not. The current README describes a **2024 extension advertised as108k complexes**, distinct from its old 2020 release. Neither advertised count is a verified usable count or a count of independent calibration units.

This lead was compared on documentary accessibility, rights and pairing—not on performance. AFLOW's explicit scientific/academic/non-commercial restriction remains a limitation. No extra request or contact is made by this recommendation.
