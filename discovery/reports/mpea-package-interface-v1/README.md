# Optional MPEA installed interface probe

Candidate `scripts/package_smoke.py` extends only the embedded installed-wheel `PROBE`. Existing top-level functions, retention API, source archive checks and atomic publication are AST-identical to the main baseline. `copy-manifest-v1.json` lists the four exact candidate destinations and patches. Two existing retention tests update only their deliberately pinned PROBE digest.

The installed probe checks the optional `resources/mpea-t25-v1.json` against `/api/benchmarks` using type-sensitive canonical JSON equality. A missing packaged resource requires an absent `mpea_archived` key, including rejection of an invented null placeholder. A present resource must be a JSON object. Successful, unsuccessful and unavailable report contents are preserved without imposing a verdict. The new `optional_mpea` smoke-result field describes resource presence and transport only. This is not a scientific schema validator or a performance claim.

The probe also requires packaged `web/mpea.js` and compares its bytes with `/mpea.js` over the installed HTTP server. This checks asset packaging and serving, not JavaScript execution or browser rendering; browser evidence remains separate.

Executed candidate checks: 16 constructed file-resource/loopback HTTP tests, 17 existing artifact-retention controls and 15 independent retention controls, all passing with 12 bound files unchanged. The new tests cover absence, exact unknown/null and unsuccessful-result preservation, changed payloads, bool/integer/float substitutions, exact strings and large integers, array order, malformed/nonfinite resources, and missing/changed JavaScript. Logs and `execution-v1.json` record the run. No actual wheel was built or installed and the complete package PROBE was not executed in this lane. Existing retention tests use inert wheel fixtures. No actual MPEA report, private scientific source, features, targets, allocation, entropy provider or live API was accessed or created.

Root owns promotion and the final installed-wheel run from the frozen release source. Temporary constructed resources remain under ignored `.cache/reviewer-controls`; all candidate/evidence paths are inside this ignored lane. Historical baseline source and tests remain under `history/`. The independent source/boundary reviewer has a separate `.cache/mpea-package-interface-review-v1/` lane.
