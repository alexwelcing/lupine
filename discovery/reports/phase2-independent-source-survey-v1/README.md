The exact documentary pairing is stronger than merely having two properties in a catalog. The paper's **File format** section and **Table 2** put scalar properties on line 2 of each molecule file. **Table 3** defines dipole moment μ in D, isotropic polarizability α in a₀³, and gap ϵgap in Ha. It explicitly defines the gap as ϵLUMO−ϵHOMO. Thus orbital energies would directly reveal that target if later allowed as predictors. Other derived thermodynamic quantities also require a feature-dependence audit. No objective, feasibility threshold, model or feature set is chosen here.

Table 2 separately identifies SMILES from GDB-17 and from B3LYP relaxation, and InChI for Corina and B3LYP geometries. These are documented identity/structure roles, not interchangeable verified keys. Molecular formula, scaffold or constitutional-isomer groups could become explicit design choices only after a separate source/frame audit. A shared molecule file documents pairing; it does not prove that every record is complete, that two identifiers denote the same optimized structure, or that molecules/groups are independent calibration units. The paper's title count is an advertised source count, not a usable or independent-unit count. No claim is made that QM9 was absent from model training or from other public benchmarks.
