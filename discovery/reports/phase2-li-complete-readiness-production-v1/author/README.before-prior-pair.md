Inner `header_replay_started/completed` describes the earlier payload-free header replay. Completion means its routine returned; `replay_matched` additionally records exact fixed projection equality. Member/decompression/UTF-8/XML counters describe subsequent metadata and selected-sheet processing. Whole-buffer identity and in-memory XML character exposure remain explicit; this is not target-free processing.

Outer operation flags distinguish reservation write attempted/may exist/created, raw-buffer read started/completed, source verification, and public write attempted/may exist. A partial source read leaves `target_bearing_source_bytes_read=null`; a successful read makes it true even if identity validation fails. A partial reservation or public write consumes its slot; retries never delete or reuse it. Late source drift, write failure, archive cleanup or directory cleanup failure clears all result payloads and retains closed exposure. Persisted bytes and the complete returned cleanup report must both be verified by the operation runner. No exception string or source canary is echoed; reasons are closed.
