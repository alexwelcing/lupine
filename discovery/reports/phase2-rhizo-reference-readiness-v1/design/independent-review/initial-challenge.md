# Independent challenge before a Rhizo provenance pass

This is a design challenge based only on the five authorized public project reports/inventories. It authorizes no source-body access, acquisition, numerical protocol or reference choice.

The smallest useful mixed-object set for enriching the **candidate-reference** provenance graph is the two already-retained target JSON objects, combined with the existing public unit-to-candidate graph. The public metadata supplies 36 material/model IDs and 43 distinct `(path, ordinal)` locations: 27 surface and 16 vacancy locations. Each location appears in four model units, giving 172 candidate edges. The 43 locations comprise 36 `DFT-PBE` and seven `experiment` declarations. These are neither 43 independent experiments nor necessarily 43 distinct publications or primary sources.

That minimal pass cannot establish which numeric reference the archived bound record actually selected. The public bound metadata reports property record counts, not bound citation/value identity. If the next deliverable promises archived selection reconciliation, it must either leave that question explicitly unknown or justify a separate frozen read of the 36 bound evidence objects. It must not infer selection from the upstream binder's documented method preference. The old inventory also lists three aggregate result/binding reports that are absent from the 110-object acquisition receipt; they are not already-retained objects by virtue of appearing in that inventory.

The mixed exposure is larger than the selected location set. Public metadata projects 57 surface entries and 28 vacancy entries: 85 positions in the two containers, of which 42 do not match this frame. Reading and decoding entire JSON containers exposes their complete target-bearing contents at the machine level. A display filter does not make the other entries unread. Citation, locator and notes strings may themselves contain targets, corrections or outcome comparisons. Excluding a field named `value` alone cannot support a blinded or outcome-unexposed claim. Any reviewed narrative projection must acknowledge possible incidental numerical exposure; public output should use the agreed closed metadata roles or reviewed paraphrases rather than arbitrary raw notes. Preserve the older mixed-documentation and historical-outcome exposure history.

The public booleans `citation_field_present`, `source_locator_field_present` and `notes_field_present` establish only projected presence. They do not reveal the raw JSON path, spelling, container shape, type, cardinality, nonempty content, primary/secondary source role or rights. An ordinal is a projected location, not a verified JSON Pointer. The next extractor must not invent a root-array or nested-field path from those booleans. Unexpected layout or ambiguous location should remain unresolved under an explicit stop rather than induce a fallback search or new source reads.

Method labels and declared citation/URL strings can document what the archive says. They do not independently verify a DOI, publication identity, calculation settings, physical conditions, reconstruction compatibility, uncertainty or actual source use. Repeated or colliding citations should remain distinct archive locations until a justified identity review supports a relation; no fuzzy merge or preferred alternative should be selected using errors. Seven alternative experimental vacancy locations must remain visible alongside DFT declarations.

Repository licensing has a different scope from primary-source rights. The prior documents report first-party data/content/code declarations and an express third-party reservation. Re-reading those declarations cannot clear imported values or determine whether a cited paper or dataset permits redistribution or derivative use. Keep declared archive license, primary-source identity, primary-source terms and proposed use as separate statuses, preserving `UNKNOWN` when evidence is absent. The proposed bounded local pass cannot verify external terms without separately scoped source evidence.

The map roles already documented are sufficient to state the intended three anchors and fourth facet, model-minus-reference sign, model-lattice geometry, historical conversion literal and linear-continuation assumption. Target/reference files alone cannot verify the archived per-model geometry, exact numerical representation, checkpoint or the actual loader's reference choice. Do not imply that a provenance pass revalidates source code or resolves those questions. A source/condition caveat can remain attached to all relevant unit-property edges without excluding a unit or declaring a physical mismatch proven.

A useful bounded result is a 43-location documentary provenance manifest with all 36 IDs and 172 candidate edges preserved, explicit unknowns, and a yes/no/unknown readiness statement for a narrowly named historical recorded-label comparison. It is not a new split, target choice, eligibility threshold, numerical completeness test, physical-bound certificate, candidate-screening benchmark or fresh transfer result. A later numeric completeness or bound-choice pass needs its own declared exposure and claim boundary.

Exact public-input hashes and documentary counts are retained in `source-bindings.json` and `public-counts.json`. These counts were computed only from the public redacted metadata; no source-body parser, source code, raw object, network route or runtime test was used.
