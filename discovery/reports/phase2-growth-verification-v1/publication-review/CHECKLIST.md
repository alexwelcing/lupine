# Frozen publication audit checklist

Preparation only until root supplies the final input manifest and authorizes the first audit. This auditor never imports the project, invokes a source reader, opens a workbook or retained package binary, or makes a network request. Its only Git operation reads the published runtime manifest.

- Bind the supplied final manifest digest; verify every declared input before and after the audit. Require the complete promotion and five-document trees, disjoint file roles and explicit authored metadata paths.
- Match every copy-ledger row to its original public bytes. Join every lossless UTF-8 wrapper to the original identity and decode it byte-for-byte. Preserve the original relocated README and allow only the declared one-link replacement. Account for every publication file, including separately authored root summaries.
- Preserve actual first failures, correction diffs and original execution receipts. Historical command and JSON paths remain provenance; do not rewrite them into invented publication links.
- Verify that all live relative Markdown links in the report tree and four Markdown project documents resolve as files in the proposed publication plus existing checkout. Record absolute/ignored provenance links separately.
- Keep all 332 runtime files identical to the published c17 source manifest. The report-only checkpoint must not install the pure layout candidate or mutate prior guarded readers.
- Check exact c17 original push CI identity and all four completed jobs; actual package/strict receipts, outputs and source preservation; retained artifact and independent byte-audit identities. These are retained observations, not new remote queries or test runs.
- Check both actual G30 outputs are identical shape matches while scientifically blocked; both G31 outputs are identical generic layout blocks, with successful cleanup, three completed local-extra areas, no decompression/XML and unknown roles. Three areas are not a total member count or a localized failing predicate.
- Bind the completed corrected public-operation audit and preserve its first obsolete-field failure. Its 19,246 runtime check calls must not be described as new test methods or scientific observations. No source reader is rerun to repair an auditor.
- Preserve BAM's permanent exposure and blind-benchmark exclusion. Document counts, same-record pairing and nominal metrology statements do not establish independent samples, prediction uncertainty or a joint error law.
- Preserve NIST guidance as qualified documentary support, including covariance and approximate coverage premises. It is not validation of BAM, Lupine or a scientific benchmark.
- Preserve the pure layout preparation's separate 33-author/27-independent final checks and earlier reviewer failures. Production prerequisite remains null, no runtime promotion or actual worksheet operation, and no scientific schema admission.
- Preserve G20 unresolved, G21 blocked and all scientific NO-GO claims. Historical records retain their earlier states; current top-level status must agree with the completed checkpoint. The bounded automation stays disabled.

The program checks byte mappings, selected structured facts and link targets. The reviewer also reads current summaries for scope and claim consistency. Neither activity proves every historical sentence, physical truth, formal Python refinement, hostile-code isolation or new-source suitability. First execution outputs are exclusive; any failure is retained before a separately reviewed correction.
