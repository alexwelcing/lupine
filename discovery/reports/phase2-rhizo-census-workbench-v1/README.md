# Stored-label census workbench evidence

The local workbench can display the already-public historical census as 16 separate property/unit/model groups, expose all 36 stored-reference comparison groups, and export the complete public report. The final preview uses compact approximate values with expandable exact fractions; it preserves counts, units, squared units, sums and means. It identifies the census as historical and exposed, with reference choice unknown and no tolerance-based success criterion. This interface evidence does not establish model superiority, physical accuracy, a fresh test set or scientific admission.
