## Single-command evidence and acceptance

Use only the frozen command `python scripts/li_v3_readiness_production.py
<layout|inventory|frame> --run <1|2>` and fixed slot. Reserve once; preserve
consumed/partially written slots, never overwrite/retry them. Capture bounded raw
stdout/stderr, process exit, launch/timeout state, start/end times, before/after

nonempty unexpected stderr, late cleanup error or lost poststate stops acceptance.
Unvalidated stdout is retained privately without echoing arbitrary text as an
approved public projection.

Public bytes must be <=2MiB and exactly canonical compact sorted-key,
ensure_ascii JSON plus one LF. Reject duplicate keys, nonfinite numbers, extra
keys, bool-as-int, invalid enums, oversized strings/collections and wrong phase
shape before summarizing content. Verify stdout equals persisted `public.json`

The reviewed CLI serializes the object returned by `inspect` after its final
output-directory close, then chooses the exit code. With this CLI, stdout is the
observable serialization of that return; it is not an independently captured
third channel. Record `returned_serialization_equals_persisted` on that precise
basis. If a separately frozen recorder also captures a returned-object artifact,
require all three byte strings to agree; it must call `inspect` only once, not
repeat an operation to manufacture comparison evidence.

The persisted file is written before final directory close. A late close failure
can therefore leave a complete-looking file while returned/stdout output is a

and no dependent prior pin is frozen. `output_may_exist` is not proof of a
