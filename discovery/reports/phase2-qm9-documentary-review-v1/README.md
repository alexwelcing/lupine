# Independent QM9 documentary gate review

The held survey supports QM9 as a documentary lead, not an admitted benchmark.
No blocking inconsistency was found within the allowed metadata, schema and
permission projections. This review read no full article, observed numerical
record, validation table, private object or source archive, and made no network
request. It ran no test, formal proof, data parser or scientific comparison.

| Gate | Supported now | What still blocks a frozen experiment |
| --- | --- | --- |
| AFLOW reuse | Official help explicitly limits use to scientific, academic and non-commercial purposes. | The stopped route cannot be represented as unrestricted release evidence. No record query or complete-pair count was established. |
| QM9 identity | DOI `10.6084/m9.figshare.978904` is registered as a Collection linked to the primary paper. | Constituent record DOI/version, exact files, sizes/checksums and archive identity remain unverified. Registry `version=null` and landing suffix `/4` do not resolve constituent versions. |
| Rights | Collection metadata declares CC BY 4.0; the paper is CC BY-NC-SA 4.0; its CC0 sentence applies specifically to associated Data Descriptor metadata. | Confirm applicable constituent-file terms and exceptions. Neither article rights nor the metadata waiver substitutes for dataset-file rights. |
| Pairing and units | The per-molecule format places scalar properties on one line; the dictionary gives dipole moment in D, polarizability in a₀³ and orbital energies/gap in Ha. | Documentary co-storage does not establish actual complete pairs, valid parsing, missingness or eligible-record counts. |
| Method and eligibility | B3LYP/6-31G(2df,p) is documented; additional calculations and an exceptions readme are separately identified. | Bind the intended constituent and method population, then freeze eligibility/missingness treatment. Do not silently pool extra-method subsets or infer eligibility from the title's count. |
| Identity and grouping | A consecutive index and distinct original/relaxed SMILES and geometry-specific InChI roles are documented. | Define artifact-scoped record keys, structure reconciliation, duplicates and any grouping rule prospectively. These strings are not interchangeable verified identifiers or independent-unit counts. |
| Feature leakage and budget | The gap is explicitly defined as LUMO energy minus HOMO energy. | Supplying those orbital energies in a supposed unseen-gap prediction directly reveals the target. Freeze an information/dependency graph, permitted features and equal acquisition/compute budgets before outcomes; audit related thermodynamic quantities and optimized-geometry provenance too. |
| Freshness and overlap | No target record was acquired in this survey; whole article XML was machine-exposed and selected methods/schema plus incidental convergence aggregates were disclosed. | No global freshness or training-exclusion claim follows. Audit exact artifact overlap and prior model/data exposure; preserve this exposure ledger rather than reset it when a new file is named. |
| Finite-archive protocol | A fixed finite archive can support a uniform-without-replacement audit without assuming physical independence between all molecules. | Freeze the complete eligible frame, unit/decision-panel definition, binary loss/estimand, policy, features, sample allocation, seeds and stopping/comparison rules. A molecule row is not automatically a decision panel. Fixed labels and uniform selection remain premises to verify operationally. |
| Scientific interpretation | These are archived calculated molecular properties at documented quantum-chemical methods. | No experimental accuracy, future-population risk, statistical power, new DFT result, or power-plant material performance is established. An explicit gas-phase qualifier is not independently established by the narrow reviewed projections and is not added here. |

The gap identity is a leakage warning, not a claim that subtracting rounded
serialized orbital-energy tokens must reproduce every stored gap token exactly.
That numerical representation question is still uninspected. Similarly,
chemical grouping may be important for a desired transfer question, but physical
independence is not an additional mathematical requirement for a genuinely
fixed finite-population uniform-subset audit. Neither observation supplies a
frame or an admission decision.

The next minimal acquisition is **metadata only** from the registry's literal
versioned collection landing page or an explicitly documented collection
manifest. Retain constituent DOI/record IDs and versions; file names, declared
sizes/checksums and literal URLs; licenses/exceptions; and links to readme,
exclusion, validation and method-subset documentation. Stop short of archive
payloads and numerical records. This can distinguish the main archive from the
additional subset and identify the exact exceptions documentation for a later
bounded review. It cannot by itself verify actual file integrity, complete
pairs or scientific eligibility. Root has assigned that metadata step to the
evidence author; this reviewer did not duplicate it.

The original mistaken Figshare **article** route's HTTP 404 is preserved. It
supports only that request outcome, not unavailability of the Collection.
The later DOI identity lookup is separately documented. All existing negative
results and unknowns remain intact; no threshold, objective, feature set, model,
split, allocation or benchmark was selected by this review.

The review is bound to the survey's unchanged 36-file inventory and handoff.

additive author projection of the already retained article permissions; it was
not in that original inventory. Its short metadata-specific CC0 sentence closes
the numeric masking ambiguity in the earlier license projection. The source
hash and locator are retained; the raw article and excluded schema/methods
projections are not republished here. See [bindings](source-bindings.json) and
[structured disposition](review.json).
