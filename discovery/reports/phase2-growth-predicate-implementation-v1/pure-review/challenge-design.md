# Independent generated-byte challenge plan

Frozen before candidate execution. Scope: synthetic header-only entrypoint, exact unchanged G31 header routine as a generic-reason differential oracle, and independently packed categorical challenges. No production guards, private/capture objects, network, XML helper, ZIP member open or decompression. The review does not admit any archive or scientific schema.

1. Pack local headers, central headers and EOCD directly, with separate overrides. Required envelope names and optional sheet names use opaque canary member bodies. The builder has no dependency on author fixtures or candidate code.
2. A header-valid baseline must complete both header traversals while scientific status stays blocked and archive acceptance false. Original G31 is called only through `_growth_zip_structure`, closing its in-memory archive; no `_inspect`/XML execution.
3. Isolate ordered global, path/name/type, central, local, growth and final-total predicates. Mutating two predicates in one member must preserve the earlier original predicate category; an early member failure plus a safely addressable later failure must report both in the supplementary audit.
4. Challenge raw central declaration truncation, extras/comments, counts, signatures and exact directory extent. Association must not be fabricated after malformed framing. Test duplicate offsets and overlapping local ranges; no unsafe local dependency may become PASS. Distinct later bounded entries remain eligible for safe independent checks.
5. Challenge local offsets before zero/inside earlier payload/near 2^32-1; fixed-header truncation, oversized name/extra lengths and body bounds. Never derive later addresses by following an earlier failed length. A failed local signature or uncertain span cannot authorize local extra interpretation.
6. Test valid and malformed local A220 spans: wrong outer ID, short payload, inconsistent declared length, wrong A028 signature and nonzero padding. Vary the withheld initial-padding word; permitted output stays invariant except explicitly allowed whole-buffer identity if any. No semantics inferred from that word.
7. Test explicit aggregate states: complete all-pass, complete observed failures, failures plus unavailable dependencies, and unavailable-without-observed-failure if representable. A pass over only a subset is never global success.
8. Patch XML/member operations to fail on invocation. Use opaque body/name/extra canaries, raw exception canaries and report key/value closure checks; no numeric metadata, member identity, arbitrary strings or payload fingerprints in the categorical projection.
9. Cleanup faults preserve earlier reason/categories and truthful partial exposure. Synthetic input type/size and known-actual identity refusal must precede relevant parsing. Inert import has no production operation.
10. Preserve the first actual test invocation and every subsequent correction, binding exact candidate/test/fixture bytes. Mutants predeclared by author are separate sensitivity evidence, not proof of full coverage.

Exact family unreachability/redundancy (for example parsed central extras after a rejecting raw preflight) is documented rather than forcing impossible bytes through a weakened source gate. Assertions use independent expected categories plus original generic-reason equivalence, not a copy of the candidate algorithm.
