# Read-only source readiness in the workbench

The CLI command `source-readiness`, existing benchmark HTTP response and
workbench now expose the same fixed documentary snapshot. It covers the Li
alloy tensile archive's first blocked XML operation and the Dryad dielectric
README access denial. Neither source is admitted for scientific benchmarking.
The [contract](../../docs/source-readiness.md) distinguishes an available
historical report from a successful scientific source operation.

The interface has plain summaries, expandable action/exposure/license details,
fixed evidence links and a complete JSON export. Missing, altered or stale
resources become explicit unavailable states. Refresh clears stale cards and
exports immediately; older responses cannot restore a superseded source view.
No source acquisition, parser, retry, model fit or decision threshold is exposed.

Validation on the integrated source:

- [142 focused Python methods](integration/python-first-execution.json) passed
  in 28.559 unittest seconds (30.541848445 process seconds), including legacy
  server behavior and all eighteen mandatory package flags. Every input held.
- [86 actual Chromium checks](integration/browser-first-execution.json) passed
  in 140.331753130 process seconds, retaining all eighty former checks and adding
  six full-app source-readiness checks. Actual local HTTP, downloaded JSON,
  six generated missing/forged responses, three response races, keyboard use,
  mobile layout and restoration passed. All 351 runtime files held; no browser
  JavaScript error was reported.
- Author backend checks passed 21 methods; independent backend checks passed ten.
  Author fixture browser checks passed eleven groups; the independent browser
  review passed 29 assertions and detected an isolated request-token mutation.
  Those controls are distinct from the full integrated browser execution.
- The installed release probe now requires an eighteenth snapshot/CLI/HTTP/asset
  identity gate. All eighteen omissions, an extra flag and reordered flags remain
  rejected. The [independent packaging review](package-review/README.md) passed
  26 static checks. Installed package execution follows publication separately.

Review corrected an initially wrong creep label to **tensile**, using the
already-published primary-paper methods. The earlier drafts and transport-only
test results are preserved; passing a snapshot identity test does not establish
that its prose is scientifically correct. The historical formal links and
checkpoint chronology noted by the predecessor claim review are also corrected
in the current documentation.
