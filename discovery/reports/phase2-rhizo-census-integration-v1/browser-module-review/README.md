The held single module exposes `check_recorded_census_workbench(page, artifacts)`.
It returns seven grouped check labels. There are no external fixture files.

Actual local HTTP test: seven groups PASS in 7.795 seconds.
The invocation immediately after the unchanged finite-planning helper passed
its 8 existing groups plus these seven groups in
19.902 seconds; the command exited 0. Both runs preserved
all copied package and module bytes and had no page errors. The first run is
retained separately; no failed test invocation occurred in this task.

The test binds the intentionally public resource to SHA-256
`a9ab9d72c6c39be9338e951b657e0587ae8f4dbe534b276b8f8f8951a7b1a63a`, compares
it to `/api/benchmarks`, checks every displayed exact metric, unit, fixed count,
contributing ID and reference comparison, and verifies the complete downloaded
JSON without coercing exact rational strings. This verifies transport/display,
not published arithmetic or a scientific inference.

Generated controls reuse the prior reviewed independent fixture and Fraction
oracle. They cover 26 rounding boundaries, positive/negative and 5000/2500-digit
limits, nine missing/blocked/malformed cases including positive 5001 digits,
stale detached exports after invalid and valid replacements, synthetic labels,
literal malicious text, independent reference-equality flags, keyboard disclosure,
accessible tables and 390/320 pixel containment. The helper restores the public
report, original navigation, viewport, scroll/focus and candidate problem.
