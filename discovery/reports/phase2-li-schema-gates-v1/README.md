## Smallest next inspection and its outputs

After the existing capture/envelope checkpoint is satisfied, freeze one source-specific disclosure amendment. It should map only reviewed header/dictionary/reference roles and coordinates, with explicit text fields allowed out. Sheet names alone cannot authenticate content. A machine custodian may decode sealed target-bearing bytes privately to resolve shared strings, but must disclose only the reviewed projection and truthfully record decoding and incidental exposure. Unexpected layout, mixed roles or unreviewed fields stop that extraction; no automatic first-row preview or whole-sheet dump.

The first output is a **documentary mapping**: role-to-column/reference-key bindings, definitions/units/codes, evidence locations and unresolved meanings. It can advance G20 without revealing measurements. Actual row pairing, completeness and lineage then need a separately reviewed **metadata roster** projection with stable private identity links and a public account of supported and unresolved joins. Neither output should include target values, example target cells, per-cell target hashes or ranker performance. Exact physical lineage must not be fabricated when the archive lacks it. Preserve the existing incidental-exposure ledger and add any real new exposure.

G20 advances only for questions actually resolved by those outputs. G21 remains blocked until a proposed population, dependence/overlap treatment, endpoint/missingness semantics and equal-budget comparison can be frozen with a defensible claim. This note chooses no target threshold, model, allocation, split, sample size or scientific acceptance rule. If the source cannot support paired provenance or a credible evaluation unit, record that source limitation and stop that claim; do not relax the criterion after outcomes. Independent agent review helps audit reasoning but creates no statistically independent evidence.
