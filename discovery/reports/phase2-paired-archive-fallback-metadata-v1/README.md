# Two archival calculation leads; neither is admitted

The bounded metadata pass found two concrete fallback leads with advertised paired-property columns and about a thousand structures each. It did **not** establish endpoint units, detailed calculation conditions, archive-data use terms, complete usable pairs or a fresh evaluation population. Li remains the primary route. No dataset, full paper, notebook or private label object was acquired, and no benchmark was selected.

The [scope](scope.json) was frozen before four ordinary HTTPS requests. All four returned HTTP 200 within the declared cap; there was no retry, redirect, alternative endpoint or access failure. The matminer `v0.9.3` release resolved to commit `cc3573b8a6b19ef32c9a06595f187615f25012de`. Its [pinned catalog](https://github.com/hackingmaterials/matminer/blob/cc3573b8a6b19ef32c9a06595f187615f25012de/matminer/datasets/dataset_metadata.json) and the two exact Crossref records support the following comparison. The [selected metadata](selected-metadata.json) retains the source field labels and documentary identities; [source bindings](source-bindings.json) identify every request and retained body.

The only explicit physical unit in these acquired catalog entries is the auxiliary `volume` field, described in cubic angstroms. Familiar conventions such as eV or GPa are **not substituted for missing source documentation**. Method labels DFT-PBE and DFPT-PBE are supported; temperature, pressure and other detailed operating or calculation conditions are not. Advertised counts are source metadata counts, not observed complete-row counts, independent calibration units or evidence that a proposed risk bound is attainable.

## What a later finite archive task could establish

If source terms, exact archive identity, units, pairing and eligibility can be bound, these leads could support a task defined over **fixed archived calculation labels**, with no new DFT. Full-frame descriptive quantities are facts about those stored labels. Uniform sampling without replacement from a fixed frame permits finite-population counting guarantees without assuming physically independent rows. That mathematical observation does not resolve frame construction, duplicate/source grouping, selection leakage or labels' physical accuracy.

Neither lead currently supports experimental validation, high-temperature/corrosion transfer, future-condition prediction or superior material discovery. Shared calculation methods and derived fields remain relevant even when physical independence is not a prerequisite for a finite-frame audit. A later proposal would need to freeze endpoints, permitted features, pairing, missingness, source grouping, selection rules and undefined/no-feasible/tied-optimum handling before target labels are opened. No such choices were made here.

Researcher output included the two selected entries and their paper abstracts, but no observation tables. The independent local reviewer also incidentally saw already-published legacy aggregate results while searching project documentation; that exposure is retained in the [ledger](exposure-ledger.json). **Decision:** two useful metadata leads, zero newly admitted scientific sources. If Li cannot meet its semantic gates, the smallest next action is a bounded primary-methods/schema and archive-rights check for `dielectric_constant`, with the elastic archive held as a second option. Root retains the source-selection decision. Do not request either data file until those documentary gaps and a label-exposure plan are resolved. This result does not complete G21 or change any current benchmark, threshold, allocation or model.
